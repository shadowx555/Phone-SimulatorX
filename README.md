# 📱 Phone Simulator

Интерактивный симулятор смартфона, который работает прямо в браузере. В проекте реализованы выбор модели, рабочий стол с приложениями, встроенный магазин **Store** с покупками и подписками, а также несколько мини-игр, музыкальный плеер и другие утилиты.

https://github.com/shadowx555/Phone-SimulatorX

## ✨ Возможности

### 📲 Два интерфейса
- **Стиль iOS** — иконки с закруглёнными углами, полоска Home внизу, экран блокировки с крупными часами.
- **Стиль Android** — круглые иконки, нижняя навигация (◁ ○ □), сетка 5×N.

### 🛍️ Store
- Каталог приложений и игр с карточками, рейтингами и описаниями.
- **Покупка** приложений за виртуальную валюту с анимацией и звуком.
- **Подписки** (неделя / месяц / год) с выбором тарифа.
- Купленные приложения автоматически появляются на рабочем столе.
- Баланс и все покупки сохраняются в `localStorage`.

### 🎮 Мини-игры
| Игра | Жанр | Управление |
|------|------|------------|
| **City Rampage** | Top-down экшн | WASD / стрелки, клик — стрельба |
| **Blocky World** | 2D-песочница | Клик — поставить блок, правый клик — сломать |
| **Plumber Jump** | Платформер | Стрелки / тапы |
| **Flappy Wings** | Аркада | Тап / Space |
| **Space Runner** | Аркада | Стрелки / тап |
| **2048 Puzzle** | Головоломка | Стрелки / свайпы |
| **Racing X** | Гонки | Стрелки / тап |

### 🎵 Музыка
- 4 оригинальные мелодии, синтезированные через **Web Audio API**.
- Плеер с прогресс-баром, переключением треков и плейлистом.
- Звуки интерфейса: открытие приложений, покупки, клики, ошибки.

### 📦 Приложения
- **Заметки** — создание, редактирование, удаление, сохранение в браузере.
- **Калькулятор** — базовые операции, проценты, смена знака.
- **Камера** — симуляция съёмки с вспышкой и звуком.
- **Фото** — сетка изображений.
- **Погода** — почасовой и недельный прогноз.
- **Настройки** — информация об устройстве, баланс, сброс данных.
- **VPN** — демонстрационный интерфейс с переключателем ON/OFF и статистикой.
- **Music Pro**, **CloudBox** — премиум-приложения по подписке.

### 💾 Сохранение
- Все данные (баланс, покупки, подписки, заметки, установленные приложения, выбранная модель) сохраняются в `localStorage`.
- У каждого пользователя — свой собственный сейв. Данные не передаются на сервер и не синхронизируются между устройствами.

## 🛠️ Технологии

- **HTML5** — разметка, canvas для игр.
- **CSS3** — Flexbox, Grid, анимации, `backdrop-filter`, `@keyframes`.
- **Vanilla JavaScript** — без фреймворков и библиотек.
- **Web Audio API** — генерация звуков и музыкальных мелодий.
- **Canvas API** — рендеринг всех игр.
- **localStorage** — сохранение прогресса.

## 🎯 Управление

| Действие | Как |
|----------|-----|
| Разблокировать экран | Клик / тап по экрану блокировки |
| Открыть приложение | Клик по иконке |
| Закрыть приложение | Home-индикатор (iOS) или ◁ / ○ (Android), либо Esc |
| Переключить модель | Выпадающий список сверху |
| Сбросить прогресс | Настройки → «Сбросить всё» |
