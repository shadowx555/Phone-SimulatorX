# 📱 Phone Simulator

Интерактивный симулятор смартфона, который работает прямо в браузере. В проекте реализованы выбор модели (iPhone / Android), рабочий стол с приложениями, встроенный магазин Store с покупками и подписками, а также несколько мини-игр и утилит.

## ✨ Возможности

- **Выбор модели**: Переключение между интерфейсами iPhone и Android.
- **Store**: Магазин приложений с имитацией покупок, подписок и анимацией.
- **Мини-игры**: 
  - City Rampage (top-down экшн)
  - Blocky World (2D-песочница)
  - Plumber Jump (платформер)
  - Flappy Wings (аркада)
  - Space Runner, 2048 Puzzle, Racing X
- **Приложения**: Музыкальный плеер (Web Audio API), Заметки, Калькулятор, Камера, Фото, Погода, Настройки.
- **Сохранение**: Прогресс (покупки, заметки, установленные приложения) сохраняется в `localStorage`.

## 🚀 Запуск

Просто откройте файл `index.html` в любом современном браузере. Установка зависимостей не требуется.

## 🛠️ Технологии

- HTML5
- CSS3 (Flexbox, Grid, анимации)
- Vanilla JavaScript (без фреймворков и библиотек)
- Web Audio API (для звуков и музыки)
- Canvas API (для игр)
